One glyph for an agent that never does just one thing: 🐙 — an octopus, eight arms
all working at once, juggling every task in parallel and dropping none of them,
which is the whole job in a single instantly readable shape.

## How it works

`main.ts` writes the single emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`), after checking it is exactly one grapheme.
